# ESP32 Keypad Lock (кодовый замок на 4 кнопках)

Учебный embedded-проект на ESP32: кодовый замок, который открывается вводом 4-значного кода с помощью четырёх кнопок. Реле управляет замком, светодиод показывает состояние, аналоговый датчик на АЦП переключает режим работы.

## Возможности

- Ввод кода 4 кнопками с программным подавлением дребезга
- Неблокирующая логика на `millis()` и конечном автомате (без `delay()`)
- Защита от перебора: после 3 неверных попыток блокировка на 30 секунд
- Управление реле и светодиодом
- Режим по датчику на АЦП (ESP32, 12 бит, порог настраивается)
- Журнал событий через Serial (115200 бод)

## Железо

| Компонент | Пин ESP32 | Примечание |
|---|---|---|
| Кнопка 1 | GPIO 5 | вторая нога на GND, `INPUT_PULLUP` |
| Кнопка 2 | GPIO 14 | вторая нога на GND, `INPUT_PULLUP` |
| Кнопка 3 | GPIO 27 | вторая нога на GND, `INPUT_PULLUP` |
| Кнопка 4 | GPIO 26 | вторая нога на GND, `INPUT_PULLUP` |
| Светодиод | GPIO 4 | через резистор 220-330 Ом |
| Реле | GPIO 17 | модуль реле, питание по даташиту модуля |
| Аналоговый датчик | GPIO 34 | фоторезистор |

Плата: ESP32 DevKit v1 (DOIT).

## Как работает

Состояния:

1. ENTRY: ожидание ввода кода. Каждое нажатие выводит `*` в Serial.
2. UNLOCKED: код верный, реле включено на 10 секунд, светодиод мигает.
3. PAUSE: пауза после открытия (10 с), после неверного кода (3 с) или после блокировки (30 с).

Если значение датчика на GPIO 34 не превышает порог `ADC_THRESHOLD` (1500), ввод кода отключается: светодиод выключен, реле включено. Опишите здесь, что это значит в вашей установке.

## Сборка и запуск

Нужны VS Code с расширением PlatformIO.

```bash
git clone https://github.com/tsumi-a/first.git
cd first
pio run -t upload
pio device monitor
```

## Настройка

Все параметры (пины, код, тайминги, порог АЦП, число попыток) находятся в начале `src/main.cpp`.

Код по умолчанию 1-2-3-4. Смените его перед использованием.
